# Publication privacy

This repository contains public-source research, original synthesis, and a newly created fictional example. Private vault contents, conversation transcripts, account credentials, local filesystem inventories, private evaluation outputs, and personal or organizational case studies are outside its publication scope.

Public paper authors, named organizations, and linked public projects identify the referenced work. GitHub necessarily displays the repository owner and account activity. Generic local Git author metadata is used for the initial research commits so they do not add a personal name or contact address.

Before initial publication, review the complete intended file set and every commit being pushed, including author/committer metadata, filenames, fixtures, and source catalogs. A pattern check can identify some local paths, private-key markers, and token formats. Independent editorial inspection is still required: a scanner does not prove that prose is anonymous or that every secret format was detected.

Do not submit private logs, credentials, screenshots, vault exports, or identifiable examples in public issues or pull requests. Use examples written from scratch with fictional entities. Check publication permission and data licenses before adding a dataset. Removing a file from the latest revision does not remove it from earlier commits or public copies.

The project makes no promise that indefinite retention is appropriate for all memory. Selection, access, deletion, preservation, and public release are separate decisions. Research on memory quality does not authorize publishing someone's memory.
