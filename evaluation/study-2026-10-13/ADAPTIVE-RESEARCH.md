# Adaptive memory: six prospective mechanisms

Reviewed on 2026-10-13, **after the main study's prospective freeze**. This research did not inform its already frozen method selection. These are **NOT EXECUTED next avenues**, rather than additions to its results or recommendations to deploy a particular system. No source system, training loop, trained checkpoint, provider evaluation, or published score was reproduced.

The [current protocol](PLAN.md) declares 21 fixed ranking policies, including neural rankers and a shallow development-trained tree. That tree learns record ranking; it does not learn provider selection, memory writing, intervention timing, or a sequence of retrieval actions. Host-mediated virtual-filesystem access and query-retrieval tests expose bounded tools and observations. Query cues can affect deterministic retrieval without establishing a learned controller. These distinctions matter: better packet coverage cannot establish better final reasoning, and a successful agent action cannot establish which memory caused it.

This review covers selected method, evaluation, and limitation sections of six primary papers, plus four official repositories' pinned READMEs, license files, tree metadata, and release listings. It is not a complete code audit. [The source catalog](adaptive-sources.json) records identities, revisions, review limits, and duplicate checks. Repository software licenses do not automatically license paper text, benchmark data, dependencies, or model weights. No new dependencies, weights, authenticated services, or private personal examples were used.

## AD01 — Conditional utility and careful credit

[MemRL](https://arxiv.org/html/2601.03192v1) retains a frozen language model while updating episodic-memory utility from task feedback. Semantic recall precedes utility-aware selection. Its utility analysis assumes a fixed inference policy and stationary task/reward distribution. The [official implementation](https://github.com/MemTensor/MemRL/tree/c1b322ca43de36ddf64c6712f89d0095bfc35ce0) has an MIT license and configurable model/embedding endpoints; weight stability does not imply a model-free system.

**H1:** Conditioning utility on applicable version and scope will preserve required evidence better than one global utility per record. Compare those two updates with frozen similarity ranking, identical candidates, and identical byte caps. Deliberately cross success histories with later supersession, scope changes, and rarely requested essential originals. Shared task success is not a record's causal importance: use paired removal/replacement probes and record competing explanations. Falsify the hypothesis if conditional utility fails to reduce stale/wrong-scope exposure, or loses rare essential spans while improving aggregate success. Keep originals regardless of low observed reuse; estimate utility for retrieval priority, not destructive forgetting.

## AD02 — Provider choice with uncertainty fallback

[MemAgent](https://arxiv.org/html/2609.32521v1) uses a Qwen3.5-4B/LoRA controller for Begin retrieval, In injection, and End storage decisions across 13 providers. It generates structured JSON decisions. All-provider probes avoid retrieval-generation calls; every provider still uses generation during storage. The [Apache-2.0 repository](https://github.com/WalkerWorldPeace/MemAgent/tree/7121cfe991c329748cd610515a3419cabc875ba6) documents training and local checkpoint paths. Its reviewed README and release listing did not identify a downloadable trained controller.

**H2:** An uncertainty-triggered fallback to multiple complementary views will recover required context more reliably than committing to one provider. Compare single-choice routing, the same router with fallback, and fixed fusion at matched returned-byte and candidate limits. Include provider disagreement, empty probes, incomplete previews, and obsolete evidence. Train only on independent development groups; do not route using answer/support labels. Count complete required-span exposure, missed constraints, fallback activations, storage work, and controller failures. Falsify the hypothesis if fallback adds context without recovering missing essentials, or raises wrong-scope exposure. A hindsight union of successful providers is an upper bound, not a deployable selection policy.

## AD03 — Descend when abstractions omit evidence

[NapMem](https://arxiv.org/html/2607.05794v1) links raw conversations, typed records, topic tracks, and profiles through provenance. Five tools expose conversation/record lookup and search plus file reading. GRPO jointly trains navigation and answering with terminal criteria for format, correctness, and using at least one memory tool. The paper leaves privacy, forgetting, and broader scaling unresolved; this review does not verify a release.

**H3:** Navigation that descends to originals when a summary leaves requirements unresolved will improve complete evidence exposure over a fixed summary-first packet. Hold the memory pyramid, access budget, and explicit requirement/span-audit objective constant; vary only the descent policy. Include good abstractions, missing exceptions, misleading current-state summaries, and absent facts. Compare fixed descent and flat original retrieval as controls. Reward verified requirement coverage and grounded answers, rather than tool count or citation appearance; permit abstention when sources cannot resolve a requirement. Falsify the hypothesis if adaptive descent misses essential originals as often as controls, or invents support when facts are absent. Retain actual tool-return spans and wrapper bytes.

## AD04 — Intervene before consequential steps

[Proactive Memory Agent](https://arxiv.org/html/2607.08716v1) maintains memory alongside an action agent and can return a grounded reminder or no intervention. Its training experiments use a Qwen3.5-27B memory model with SFT/GRPO; the untrained memory model hurts performance in the reported comparison. The [Apache-2.0 repository](https://github.com/yifannnwu/proactive-memory-agent/tree/89e5c0d6aadfe531a1aee42fd290d48be89973dd) exposes implementation code, but reviewed release metadata does not establish trained-weight availability or CPU feasibility.

**H4:** Reminders triggered immediately before consequential steps will reduce missed requirements more than injecting the same memory at every step. Hold the action agent, source bank, reminder generator, and cumulative context allowance constant; compare triggered, always, and disabled intervention. Author steps requiring exact action parameters, known gotchas, and premise checks, alongside steps where memory is irrelevant. Measure parameter violations and missing prerequisites before action, successful recovery, unnecessary reminders, and supporting spans delivered before the decision. Falsify the hypothesis if selective timing merely shifts failures later, or suppresses a rare necessary reminder. A readable reminder is not proof of compliance.

## AD05 — Guard adaptations with independent evidence

[EvolveMem](https://arxiv.org/html/2605.13941v1) evaluates failures, diagnoses them, proposes changes, and guards revisions with rollback and coverage expansion. Retrieval settings and answer styles both evolve. Its 28-sample MemBench subset crosses seven categories with two topics; an illustrated connector-word repair changes F1. Related variants and score-tuned styles therefore warrant a generalization check. The [MIT SimpleMem repository](https://github.com/aiming-lab/SimpleMem/tree/db80b6a7c591e0ea730a058e9f5fc4eb06572299/EvolveMem) contains EvolveMem code and documentation, not evidence that its full loop was executed here.

**H5:** An independent guard set will reject adaptations that improve tuning scores while damaging source coverage or requirement satisfaction. Compare the same bounded proposal stream with an independent guard, an in-sample guard, and a frozen no-change control. Separate retrieval edits from answer-style edits. Use newly authored development, guard, and sealed held-out groups; repeated guard use is itself tuning and must be disclosed. Freeze the acceptance rule before proposals. Preserve source-linked before/after receipts and verify rollback restores exact configuration and artifacts. Falsify the hypothesis if accepted gains vanish under wording-insensitive requirement/span audits, or if the independent guard admits the same held-out regressions.

## AD06 — Observe executed procedures, not labels alone

[Supra Cognitive Modes](https://arxiv.org/html/2607.19096v1) maps four frozen semantic labels to configurations whose runtime gates can change procedures. Its paper distinguishes bundled-system comparisons from causal routing evidence: fixed-policy controls, some final procedure traces, paired disabled outputs, and aligned timing are missing. The reviewed source supports a control-interface description, not a routing benefit or CPU speed claim.

**H6:** Query-conditioned dispatch will improve required-context coverage over fixed procedures when all other components remain identical. Compare routed dispatch with each fixed procedure on identical corpus snapshots; keep synthesis settings and bytes matched. Log requested mode, initial payload, every override, final procedure, returned original spans, and the exact answer path whose latency/tokens are measured. Include deliberately misleading temporal and synthesis cues. Persist both enabled and disabled outputs. Falsify the hypothesis if gains disappear in fixed-procedure controls, depend on unequal context, or cannot be assigned to the recorded executed path. Semantic labels are telemetry categories, not evidence of cognitive or neurological mechanisms.

## A prospective execution boundary

Any follow-up needs a separate frozen plan, fresh source-linked fixtures, explicit failure accounting, and a declared execution budget. Report paired changes by history/template groups, including rare requirements, regressions, and unresolved cases; do not treat many variants of one history as independent evidence. Audit the distinction between candidate IDs, partially exposed sources, complete originals, and sufficient original spans. Neither citations nor an aggregate reward alone establish entailment.

Accuracy and all important context take priority over price here. Record bytes, controller/storage work, latency, and failures as separate costs after measuring coverage and requirement satisfaction. A cheaper decision that silently drops an essential exception fails this objective. No universal best taxonomy, general superiority of learned memory, neuroscience proof, or replacement of the frozen study follows from this source review.
