# Memory entry point

Scope: a fictional local export project. Source records live in `episodes/`; a derived brief lives in `state.md`. IDs refer to records and, where available, individual messages.

The brief states its incorporated-evidence boundary. It can lag later records. File editing dates describe file maintenance; they do not establish the effective date or authority of a decision. Read the relevant original messages and tool results before continuing work.

The collection preserves proposals, decisions, and attempts as different kinds of evidence. Absence of a record is not proof of an approval. The task prompt defines the allowed workspace; memory does not grant access to external accounts.
